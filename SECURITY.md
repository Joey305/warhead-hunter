# Security policy

Please do not report vulnerabilities in public issues. Send a concise private
report, reproduction steps, and impact assessment to
[jmschulz@med.miami.edu](mailto:jmschulz@med.miami.edu?subject=Private%20security%20report%20for%20Warhead%20Hunter).

We will acknowledge receipt, assess the report privately, and coordinate a fix
before any public disclosure.
